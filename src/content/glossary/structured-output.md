---
term: 'Structured output'
area: methods
definition: >-
  Asking a language model to answer in a fixed format, such as JSON that matches a schema,
  then validating it before use. Windchime’s planner fills a template schema that a validator
  clamps, so no model ever writes the Strudel code itself.
related: [guarded-planner, validation-gate, prompt-injection]
